# סימולציית הוראה אינטראקטיבית (AI Chat + Whiteboard + SVG + LaTeX)

תבנית נקייה ומהירה לאפליקציית סימולציה בעברית (RTL) המבוססת על **HTML/CSS/JS** טהור בצד הלקוח ו-**Vercel Edge Function** בצד השרת — ללא צורך ב-`npm install`, ללא ספריות כבדות וללא תהליך Build.

---

## מבנה הפרויקט

* `index.html` — ממשק 3 עמודות (RTL):
  * **ימין:** כרטיסי אווירה והקשר (משימה, פרופיל תלמיד, מחברות).
  * **מרכז ("הלוח"):** לוח כתיבה וציור אינטראקטיבי (עט, צורות, מחק, צבעים, Undo/Redo) + שכבת SVG מצטברת שמתעדכנת אוטומטית מהצ'אט.
  * **שמאל ("השיחה"):** צ'אט AI בזמן אמת (Streaming), כפתור 3 מצבי מהירות/חשיבה, תמיכה בנוסחאות מתמטיות (KaTeX), ומונה טוקנים ומעקב מודל זעיר מתחת להודעות.
* `api/chat.js` — פונקציית שרת שרצה ב-**Vercel Edge Runtime** ומחברת בצורה מאובטחת ל-Google Gemini API.
* `landing.html`, `tic-tac-toe.html` — דפים צדדיים המקושרים מהסרגל העליון.

---

## איך משכפלים לפרויקט חדש (GitHub + Vercel)

1. ב-GitHub, הפוך את המאגר ל-**Template repository** (תחת `Settings`), ולחץ **`Use this template`** ליצירת פרויקט חדש.
2. חבר את המאגר החדש ל-**Vercel**.
3. ב-Vercel, היכנס ל-**Settings → Environment Variables** והוסף:
   * `GEMINI_API_KEY` — מפתח ה-API מ-Google AI Studio.
   * *(אופציונלי)* `GEMINI_MODEL` — אם תרצה לדרוס את מודל ברירת המחדל (`gemini-3.5-flash-lite`).
4. להתאמת הסימולציה לנושא חדש:
   * עדכן את `SYSTEM_INSTRUCTION` בראש `api/chat.js`.
   * עדכן את כרטיסי התוכן בעמודה הימנית ואת שאלות הפתיחה ב-`index.html`.

## כללי תשתית ולקחים טכניים (לפיתוח עתידי עם סוכן AI)

מסמך זה מרכז את הדקויות שנפתרו בפרויקט כדי שלא לחזור עליהן בפרויקטים הבאים:

1. **שימוש ב-Vercel Edge Function ולא Node.js רגיל:**
   * ב-`api/chat.js` מוגדר `export const config = { runtime: 'edge' }`.
   * זה מבטל כמעט לגמרי את זמן ההתעוררות (Cold Start) ומעלה את מגבלת הזמן לפתיחת תגובה מ-10 שניות ל-**25 שניות**.

2. **ביטול טיימר החיבור מיד עם פתיחת הסטרים:**
   * אסור להשתמש ב-`AbortSignal.timeout()` ישירות על `fetch()` של סטרימינג, כי ב-Node/Edge הטיימר נשאר פעיל גם תוך כדי קריאת הגוף וחותך תשובות ארוכות באמצע (`The operation was aborted due to timeout`).
   * יש להשתמש ב-`AbortController` ולבצע `clearTimeout(timer)` **מיד** כשכותרות התשובה חוזרות מ-`fetch`.

3. **הזרמה בזמן אמת (SSE Streaming) + החזרת JSON תקינה בשגיאה:**
   * החיבור ל-Gemini נעשה דרך `streamGenerateContent?alt=sse`.
   * בכל שגיאה שלפני פתיחת הסטרים השרת תמיד מחזיר `JSON` מסודר (`{ error }`) כדי שהממשק לא ייתקע במצב טעינה.

4. **בחירת מודלים ו-Fallback חכם:**
   * המודל הראשי מקובע ל-`gemini-3.5-flash-lite`, והגיבוי הראשון הוא `gemini-3.1-flash-lite-preview`.
   * גיבוי נוסף מול `ListModels` נשמר ב-Cache ל-5 דקות ומסנן **אך ורק** מודלי `flash` מסדרה שמעל `2.5` (תוך סינון החוצה של מודלים סגורים/ייעודיים כמו `argon`, `pro`, `ultra`, `exp`, `tts`, `image`, `robotics`).

5. **שליטה ב-3 מצבי מהירות/חשיבה בתוך אותו מודל:**
   * הממשק מעביר `speedMode`: `fast` (`thinkingBudget: 0`), `balanced` (`1024`), `accurate` (`8192`).
   * אם המודל דוחה `thinkingConfig` (`400`), השרת מנסה שוב על **אותו מודל** ללא `thinkingConfig` לפני שהוא עובר למודל גיבוי.

6. **הפרדת צ'אט מול לוח וטיפול ב-SVG:**
   * ה-AI מונחה לצייר **רק את הצורה החדשה** שביקשו בהודעה הנוכחית ועל **רקע שקוף** (בלי מלבן רקע כהה).
   * הלוח המרכזי **צובר** את השרטוטים, וכל SVG עובר סניטציה + חיתוך שוליים אוטומטי (`getBBox()` עם padding של `14` יחידות).

7. **תצוגת מתמטיקה (LaTeX / KaTeX) בתוך עברית (RTL):**
   * טקסט התשובה מוצג עם `textContent` (למניעת XSS) ומרונדר עם `renderMathInElement` של KaTeX (`$...$`, `$$...$$`, `\(...\)`, `\[...\]`).
   * חובה להשאיר `direction: ltr; unicode-bidi: isolate;` על `.katex` ו-`.katex-display` כדי שנוסחאות ושברים לא יתהפכו.

8. **מעקב גרסאות:**
   * בכל עדכון של הממשק יש להקפיץ את מספר הגרסה בכותרת `index.html` (`סימולציה גרסה X`) כדי לוודא שבוצע deploy עדכני ב-Vercel.
